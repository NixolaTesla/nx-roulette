# Overview


A text-based version of the classic game of russian roulette!


# Requirements:

-must have **gcc** (or any other **compiler** to compile nxroulette.c into an executable, but you will end up having to that manually)

# Installation and Setup

# **1.** Clone the repository
# **2.** Enter the nx-roulette/nxroulette directory
# **3.** Compile either with the **Makefile** or manually. (gcc nxroulette.c -o nxroulette)
# **4.** Run "./nxroulette" or replace it with whatever the name of your executable is.
# **5.** **Enjoy!**
